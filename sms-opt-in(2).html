How PonyUp uses text messages

PonyUp uses SMS for one purpose only: sending a one-time verification code so you can sign in to your account.

This page explains exactly when we text you, what those messages say, and how to stop them. It is here so you — and the mobile carriers who deliver our messages — can verify how PonyUp's messaging works.

Who we are

PonyUp is a mobile app that helps friends follow through on shared plans. It is operated by an independent developer as a sole proprietor. Verification text messages are sent through Twilio.

How you opt in to receive a code

You receive a text only after you enter your own phone number in the app and ask for a code. We never add you to any list, and we never message you unless you request a code.

  1. You open the PonyUp app and reach the sign-in screen.
  2. You type your own mobile number into the phone field and tap Send Code. Shown right by that button is this notice: “By tapping Send Code, you agree to receive a one-time verification code from PonyUp by text to confirm your number. Msg & data rates may apply,” with links to these Terms and Privacy Policy. Tapping the button is your request for, and consent to receive, that code.
  3. We text you a single 6-digit verification code.
  4. You enter that code in the app to finish signing in.

What our messages look like

Every message is a verification code and nothing else. Examples of the texts we send:

PonyUp: Your verification code is 123456. It expires in 10 minutes. Don't share this code with anyone.
PonyUp: 845102 is your login verification code. Enter it in the app to sign in. This code expires in 10 minutes.

How often we message you

You get one message each time you request a code, which normally happens when you sign in. Message and data rates may apply. PonyUp does not send marketing, promotional, or recurring messages.

Stopping messages and getting help

Reply STOP to any message to opt out of further texts. Reply HELP for help. These replies are handled automatically.
